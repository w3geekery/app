**Title:** `Deprecate Engagement, SmeMartProject, EngagementVettingItem (Phase 29.5)`

**Body:**

SME Mart Phase 29.5 migrates engagement/project modeling from GQL classes to the new `platform.Project` / `platform.Board` primitives. This PR marks the three legacy classes as deprecated without deleting them, following the "deprecate-without-delete" strategy (Decision D-26/D-27 in the Phase 29.5 brief).

**Deprecate-Without-Delete Strategy:**
The three classes remain in the schema during a dual-read window (Phases 29.5–31) so existing demo data remains readable. App-side writes have stopped (provisioner moved to `platform.Project.create`); reads fall back to GQL as a fallback if new path unavailable. Delete is deferred to post-Phase-31 closure when all readers have migrated to the new entities (see backlog item `SCHEMA-RETIREMENT-DELETE-1` — not calendar-gated).

**Replacement Map:**
- `Engagement` → `platform.Project` (top-level, `parentId=null`, identity tag via `tagId`)
- `SmeMartProject` → `platform.Project` (child, `parentId=engagement.id`, tagless)
- `EngagementVettingItem` → `platform.Task` on `platform.Board` (`boardType='list'`)
