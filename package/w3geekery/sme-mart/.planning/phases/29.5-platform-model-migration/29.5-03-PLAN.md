- **Standalone components only** → no NgModule imports

## ZeroBias SDK patterns
- **Client injection:** `inject(ZerobiasClientApi)` returns singleton with `.platformClient`, `.hydraClient` accessors
- **Dual-read window (D-15):** Primary = `platformClient.getProjectApi().listProjects({ parentId: null })` filtered by boundary; fallback = existing GQL SmeMartProject search on read timeout or 404
- **Error handling:** Catch platform API 404/timeout → log + retry GQL path; don't surface to UI
- **Demo org filtering:** Post-read via `DemoVisibilityService.applyVisibility()` (polymorphic over both shapes)
- **Org scoping:** Current org from `getPrincipal().principalId` (principal scoped); use `getPrincipal().orgId` for boundary validation
