## Key Decisions

1. **Promise.race() for timeout racing** (not sequential try-catch): Allows primary read to be abandoned at 5s timeout without waiting full timeout period. Secondary timeout also 5s (configurable per D-15 requirements).

2. **Polymorphic demo-visibility via type guard, not union constraint**: Loosened applyVisibility generic to accept any type `<T>`, with internal safe cast to TagField for isLocalDemoTagged. More flexible than strict constraint, avoids type mismatch errors across caller code.

3. **SmeMartProjectService name unchanged** (D-17/D-18): Service implementation swapped from Pipeline.receive to platform.Project SDK, but name retained for backward compat with injected clients.

4. **Transformation layer keeps SmeMartProject shape**: Platform.Project fields mapped to SmeMartProject with defaults for unavailable fields (engagementId=null, RFP fields=null). Allows incremental data migration without breaking downstream consumers.
