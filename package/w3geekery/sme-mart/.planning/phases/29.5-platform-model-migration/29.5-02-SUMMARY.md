### ✅ Task 2: 5-Step Recipe Rewrite
**File:** `src/app/core/services/platform-engagement-provisioner.service.ts` (lines 60–389)

**Completed:**

#### Signature & Return Type
- **Old:** `ensurePlatformEngagement({currentOrgId, currentOrgName, currentOrgSlug, buyerUserId, assignedPartyId, accountablePartyId})`
- **New:** `ensurePlatformEngagement({currentOrgId, currentOrgName, currentOrgSlug, adminPrincipalId})`
- **Old return:** `{engagementId, projectId, created}`
- **New return:** `{engagementProjectId, workspaceProjectId, boardId, created}`

#### Orchestrator Flow (ensurePlatformEngagement, lines 119–154)
1. **Probe:** `isOrgProvisioned(currentOrgId, currentOrgName, currentOrgSlug)` → if true, return `{created: false, engagementProjectId: '', workspaceProjectId: '', boardId: ''}`
2. **Step A:** `ensureTag()` — create hydra tag for engagement identity (marketplace operator ownerId)
3. **Step C:** `ensureEngagementProject()` — create engagement Project (parentId=null, ownerId=buyerOrgId, tagId=identityTag)
4. **Step D:** `ensureWorkspaceProject()` — create workspace Project (parentId=engagementId, ownerId=buyerOrgId, tagless per D-02)
5. **Step F:** `ensureDefaultBoard()` — create kanban board on workspace project (isDefault=true)
6. **Step G:** `ensureProjectMember()` — add admin principal to engagement project with admin role
7. **Return:** `{engagementProjectId, workspaceProjectId, boardId, created: true}`

#### Dropped Steps (per D-08)
- **Step B (ensureTask):** Removed — no longer part of recipe
- **Step E (ensurePipelineLink):** Removed — no longer part of recipe
- Both removed with comments explaining D-08 verification gate decision

#### Error Handling (consistent across all steps)
```
try {
  // attempt step
} catch (err) {
  console.warn('[PLATFORM_ENGAGEMENT_FAILURE]', {
    step: 'X',
    callSiteTag: 'platform-engagement:ensure-xxx',
    error: err,
  });
  this.snackBar.open('Setup in progress — please retry in a moment.', 'Dismiss', { duration: 5000 });
  throw err;
}
```

#### Step Methods (idempotency pattern for all)
1. **ensureTag (Step A):** Probe via `hydra.Tag.searchTags({name})`, return cached if exists, else create
2. **ensureEngagementProject (Step C):** Probe via `platform.Project.list({ownerId, tagId})`, return cached if exists, else create with locked name `${orgName} <- ZeroBias`
3. **ensureWorkspaceProject (Step D):** Probe via `platform.Project.list({parentId})`, return cached if exists, else create tagless with locked name `ZeroBias Platform`
4. **ensureDefaultBoard (Step F):** Probe via `platform.Board.list({projectId})`, find `isDefault=true`, return cached if exists, else create kanban board
5. **ensureProjectMember (Step G):** No probe needed (idempotent at API level), add principal with admin role

**Decisions locked:** D-01, D-02, D-04, D-06, D-08, D-29, D-30, D-32, D-33, D-34, D-35
