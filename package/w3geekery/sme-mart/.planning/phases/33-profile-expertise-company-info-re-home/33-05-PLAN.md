Create a standalone, modern Angular 21 multi-select picker component for Catalog Service segments (133 leaf nodes under the Services domain, per D-56 Option B).

**Component signature:**
```typescript
@Component({
  selector: 'app-service-segment-picker',
  standalone: true,
  imports: [ZbSimpleMultiAutocompleteComponent, ...],
  template: `...`,
})
export class ServiceSegmentPickerComponent {
  @Input() selectedSegmentIds = input<string[]>([]);
  @Output() segmentsChanged = output<string[]>();
}
```

**Behavior (per UI-SPEC §1):**
1. Load Catalog Service segments on init via `CatalogService.findSegments()` (filtered to `segmentType: service`).
2. Render a `ZbSimpleMultiAutocompleteComponent` with:
   - Placeholder: "Search or browse services…"
   - Options: array of { id: segmentUuid, label: segmentName } for the 133 leaf nodes
   - Multi-select: user can select multiple services (typical use: 2–5 per provider)
   - Typeahead: user can type to filter by name (case-insensitive prefix match)
3. Render selected services as removable chips below the input.
4. On change, emit `segmentsChanged` event with array of selected segment UUIDs.

**Optional enhancement (UI-SPEC mentions category-browse):**
If time permits, add a left pane showing the 37 Service categories. Clicking a category narrows the typeahead to services in that category. Purely optional; core requirement is typeahead + multi-select.

**Loading state:**
Show a Material spinner while CatalogService.findSegments() is pending. Display a fallback "No services available" if the loader returns empty (edge case).

**No-match state:**
If user types a search term with no matches, show: "No services match 'xyz'. Try another keyword."

**Integration with expertise form:**
The component will be embedded in the my-profile-expertise component (or called via MatDialog) to let users select service segments for their profile. The selected segment UUIDs flow back to the expertise component, which calls `provider-profiles.service.ts.addServiceSegment(orgId, {serviceSegmentId, isPrimary})` for each selected UUID.

**Angular 21 compliance:**
- Standalone component
- `input()` / `output()` (not @Input/@Output)
- Use `signal()` for local state
- `@if` / `@for` (not *ngIf / *ngFor)
- `inject()` CatalogService (not constructor injection)
- `OnPush` change detection
- No `any` types
- Type-suffixed filenames (`.component.ts`)

**Styling:**
Use Material form-field + mat-form-field appearance="outline" for the input. Apply ZbChipColorsDirective (or Material chip styles) to selected items. Use design tokens for colors.
