Create standalone component `EngagementBoardsTabComponent` that owns engagement-scoped board fetching and pin-state management, wiring the shared `boards-grid` component.

**Component structure:**

Selector: `app-engagement-boards-tab`
Standalone: true
Imports: `BoardsGridComponent` + Angular framework modules
Change detection: `ChangeDetectionStrategy.OnPush`

**Input signals:**
- `engagementId` (from parent engagement-detail): required string

**State signals:**
- `boards` = signal<Board[]>([])
- `pinnedBoardIds` = signal<string[]>([])
- `loading` = signal<boolean>(true)
- `error` = signal<string | null>(null)

**Services injected (L-12 parent owns data):**
- `ZerobiasClientApi` — board fetch via SDK
- `PinStorage` — pin-state persistence (from Plan 05; tabs calls interface contract; implementation deferred)
- `Router` — navigation on drill
- `ActivatedRoute` — engagement ID from parent route

**ngOnInit sequence:**
1. Extract engagement ID from `this.route.parent?.snapshot.params['id']`
2. If no ID, set loading=false, return
3. Fetch boards:
   ```
   const result = await this.clientApi.platformClient
     .getBoardApi()
     .list(1, 50, undefined, undefined, undefined, engagementId);
   this.boards.set(result?.items ?? []);
   ```
4. Load pin-state from storage:
   ```
   const orgId = this.getCurrentOrgId(); // from ZerobiasAppService
   const saved = await this.pinStorage.getPins(orgId);
   this.pinnedBoardIds.set(saved);
   ```
5. Set `loading.set(false)` in finally block

**Event handlers:**

`onBoardClick(boardId: string):`
- Navigate to board detail: `this.router.navigate(['/boards', boardId])`

`onPinToggle(boardId: string, isPinned: boolean):`
- Update pinnedBoardIds signal:
  ```
  const current = this.pinnedBoardIds();
  const updated = isPinned
    ? [...current, boardId]
    : current.filter(id => id !== boardId);
  this.pinnedBoardIds.set(updated);
  ```
- Persist via PinStorage:
  ```
  const orgId = this.getCurrentOrgId();
  this.pinStorage.savePins(orgId, updated).catch(err =>
    console.error('[EngagementBoardsTab] Pin save failed:', err)
  );
  ```

**Error handling:**
- Wrap board fetch in try/catch; set error signal on failure
- Log to console (no user-facing alert for now; boards just show empty)

**Template:**
```html
@if (loading()) {
  <mat-spinner diameter="48" />
} @else if (error()) {
  <div class="error-message">{{ error() }}</div>
} @else if (boards().length === 0) {
  <div class="empty-state">
    <p>No boards yet</p>
  </div>
} @else {
  <app-boards-grid
    [boards]="boards()"
    [pinnedBoardIds]="pinnedBoardIds()"
    (cardClicked)="onBoardClick($event)"
    (pinToggled)="onPinToggle($event.boardId, $event.isPinned)"
  />
}
```

**Styling:**
- Spinner centered
- Error message in red; empty state in neutral gray
- boards-grid inherits parent padding

**Per modernization rules:**
- Rule 1: Standalone component
- Rule 2: Signal-based I/O (input from parent route, state signals)
- Rule 3: DI via inject()
- Rule 4: Signals for state (not BehaviorSubject)
- Rule 6: OnPush
- Rule 7: @if / @else syntax
- Rule 8: No `: any` types; proper error typing
