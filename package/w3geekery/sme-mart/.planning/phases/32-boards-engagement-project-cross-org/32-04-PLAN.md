## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-04-01 | Tampering | Form input name/description | mitigate | Validators on FormControl (required, minLength); Material form validation UI; server-side validation deferred to SDK (BoardApi.createBoard) |
| T-32-04-02 | Tampering | boardType dropdown | mitigate | mat-select restricts values to predefined options (enum-like); SDK validates boardType on server; no free-form input |

| T-32-04-04 | Denial of Service | Rapid form submission | mitigate | isSubmitting signal disables submit button during API call; user cannot spam requests; single in-flight request enforced |

</threat_model>
