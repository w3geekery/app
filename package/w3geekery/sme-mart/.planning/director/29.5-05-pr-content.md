```markdown
## Summary

Mark three SME Mart schema classes as deprecated (not deleted) to signal the model migration
that ships in SME Mart Phase 29.5.

The migration moves engagement / project / vetting-item modeling onto the new platform
primitives in `@zerobias-com/platform-sdk@1.1.16+` (`platform.Project`, `platform.Board`,
`platform.Task`). Writes for these three classes have moved off in the app; reads stay on a
dual-read window so existing demo data remains readable.

## What changes

Three class definitions in `package/w3geekery/smemart/classes/` get a top-level `deprecated: true`
flag plus a "**DEPRECATED (Phase 29.5):**" prefix on each class description that names the
replacement primitive(s).

| Legacy class | Replacement |
|---|---|
| `Engagement` | top-level `platform.Project` (parentId=null, ownerId=buyerOrgId, identity tag via `tagId`) |
| `SmeMartProject` | child `platform.Project` (parentId=engagement.id, tagless) |
| `EngagementVettingItem` | paired `platform.Task` on `platform.Board` (boardType=`list`; parent task + one subtask per side) |

## Deprecate-without-delete strategy

The three classes are NOT deleted in this PR. Deletion is a separate follow-up tracked as
`SCHEMA-RETIREMENT-DELETE-1` and is gated on dual-read having zero remaining readers — not a
calendar date. The dual-read window stays open across SME Mart Phases 29.5 → 30 → 31 while
existing demo data ages out.

## Files changed

- `package/w3geekery/smemart/classes/Engagement.yml`
- `package/w3geekery/smemart/classes/SmeMartProject.yml`
- `package/w3geekery/smemart/classes/EngagementVettingItem.yml`

## Context

Full migration brief: `package/w3geekery/sme-mart/.planning/director/phase-29.5-brief.md` in the
SME Mart app repo. Locked decisions D-13 (deprecate without delete), D-25–D-27 (deprecation
scope), and D-15 (dual-read window) drive this PR.
```
